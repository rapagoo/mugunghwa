## 8장 수치와 근거

현재 그래프의 `PyTorch 12.76 / FP16 18.53 FPS`는 서로 다른 분류의 라벨이다. **PyTorch FP32 / TensorRT FP16**으로 맞춘다. 그래프 제목은 **'사람 검출 엔진 비교: 처리량 약 1.45배'**처럼 측정 대상을 먼저 드러낸다.

수치 근거는 [엔진 최적화 기록](jetson-engine-optimization.md)의 2026-10-06 저장 영상 비교다.

| 조건·지표 | PyTorch FP32 | TensorRT FP16 |
|---|---:|---:|
| 처리량 | 12.76 FPS | 18.53 FPS |
| 프레임 처리 평균 | 78.37 ms | 53.97 ms |
| 프레임 처리 p95 | 85.67 ms | 56.44 ms |
| 사람 검출 프레임 | 594/598 | 594/598 |

조건: 동일 960×540 저장 영상 598프레임, YOLOv8n 사람 검출, 실제 입력 1×3×384×640, 신뢰도 0.35·ByteTrack, 준비 5프레임 뒤 순차 실행. 화면·파일 저장·Pi 통신 비용 제외. 처리 시간에는 입력 읽기·검출/추적·기하 계산이 포함된다. 현재 관절 게임 전체의 FPS나 카메라에서 장치까지의 반응 지연이 아니다.

정답 주석 기반 정확도는 측정하지 않았다. 동일 검출 프레임 수는 정확도 동일의 증거가 아니다. 기존 PyTorch 출력 대비 FP16 박스 IoU 평균 0.993876/최소 0.934298은 출력 일치도이며 정답 정확도가 아니다. 이 구분은 노트에 남기고, 본문에서는 '이 영상의 검출·추적 관측 수 유지' 범위로만 설명한다.

세 개선은 다음처럼 읽히게 정리한다.

- FP16: 별도 비교에서 계산 처리량 개선 수치가 있다.
- 최신 프레임: 오래된 화면이 대기하지 않도록 처리한다.
- 미리보기 간격 분리: 화면 출력 주기를 분석 주기와 나눈다.

**1.45배를 세 개선의 합산 효과나 현재 게임의 정확도·반응 속도 개선 배수로 말하지 않는다.** 13px 캡션만으로 중요한 측정 범위를 전달하기보다 '사람 검출 엔진 별도 비교'를 그래프 가까이에 크게 둔다. 장을 추가할 필요는 없다.

## 사진 없이 먼저 수정할 수 있는 부분

1. 긴 제목을 줄이고 각 장의 한 가지 주장을 구체화한다. 특히 5·7·8장.
2. 8장 그래프 라벨·측정 범위를 정리하고 지연·정확도 한계는 노트로 보강한다.
3. 3·7장의 역할을 장치 설명/동작 순서로, 6·8장의 역할을 현재 판정 원리/변경 이유로 구분한다. 기존 순서를 바꾸지 않아도 된다.
4. 9장에 DB 기록 증거를 넣을 공간과 라벨을 잡는다.
5. 청중용 화면에서는 A/B·배정 시간·'사진으로 교체 가능' 같은 편집 안내를 숨길 계획을 세운다. 발표자 노트에는 유지한다. 예시 화면을 쓰는 동안 '개념도/표시 예시'는 남긴다.
6. 실명 OOO/XXX와 최종 코드 근거 버전은 마무리 단계에서 갱신한다. 오래된 링크를 현재 버전 전체 검증 근거로 소개하지 않는다.

사진은 1·3·4·5·9·10장에 교체 연결이 준비돼 있다. 6·8장 전후 장면과 7장 영상은 현재 `photos.js` 단순 등록만으로 들어가는 구조가 아니므로, 나중에 별도 배치를 편집해야 한다. 동작하는 도식은 사진과 함께 남길지 장별로 판단한다.

## 남은 확인

2026-10-12 후속 확인: 로그를 파일로 분리한 로컬 서버 `http://127.0.0.1:8087/`에서 HTTP 200과 인앱 브라우저 첫 장 표시·스크린샷을 확인했다. 아래 접속 실패는 최초 검토 시점 기록이다. 전체 10장 시각 검증은 아직 하지 않았다. 자세한 조사·복구는 [TS-PRESENT-001](troubleshooting.md#ts-present-001)을 참고한다.

- 현재 실행 환경에서 미리보기 접속이 시간 초과되어 새 화면 캡처를 얻지 못했다. 실제 브라우저로 10장·8장 강조 상태를 확인해야 한다.
- 1280×720 기준 스타일에서 본문 24~26px, 보조 문구 13~19px가 섞여 있다. 소스 크기만으로 가독성을 확정할 수 없다. 실제 발표 화면에서 보조 문구·그래프·LCD 글자를 확인한다.
- N 대본 패널은 같은 관객 화면에 대본을 띄우는 기능이다. 발표자 분리 화면은 별도로 실행·확인한다.
- 실제 공동 낭독 시간은 미측정이다. 설명 550초+전환 50초는 배정이며 실측 결과가 아니다. 추후 영상이 본문에 들어가면 설명 시간을 그만큼 조정한다.
