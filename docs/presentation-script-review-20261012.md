## 조치와 검증

- 8장 135초 전체를 박정환 담당으로 변경했다. 7장 끝 홍성록→박정환, 8장 끝 박정환→홍성록 인계로 정리했다. 8장 안에서는 발표자 교체 없이 방향키로 2·3번 강조를 진행한다.
- 기존 공유용 대본은 10장·임시 이름·옛 마무리로 남아 있어 최신 11장 웹 노트에서 다시 추출했다. 공유용 MD와 6차 MD가 동일하고, 노트의 발화/진행 안내 65개 블록이 공유용에 모두 포함됨을 확인했다. 출처·상세 측정 조건은 웹 노트에 보존한다.
- 6장 노트의 ‘확인 확인합니다’와 붙은 표현을 수정했다. 2장 ‘서버실’은 화면의 일반적인 별도 위치 표현에 맞췄다. 3장 GAME WAITING/READY! 안내를 추가했다. 7장 움직임 판정 용어를 화면과 맞췄다.
- 8장 수치는 PyTorch FP32 12.76FPS / TensorRT FP16 18.53FPS, 약 1.45배 처리량으로 읽도록 정리했다. 별도 사람 검출 모델 비교이며 화면·저장·Pi통신 제외, 현재 관절 게임 전체 성능이 아님을 발화에도 반영했다. 이번에 성능·정확도·지연을 재측정하지 않았다.
- 9장 결과 공유, 10장 시연 한 문장, 11장 놀이공원 활용 방향이 최신 슬라이드와 대응함을 검토했다. 시연의 수치/시간은 설명용이며 실제 경기 기록으로 소개하지 않는다. 놀이공원 적용은 향후 방향으로 표현한다.
- 브라우저에서 8장 대본 제목 ‘박정환 · 135초’와 세 사례·9장 인계를 확인했다.
