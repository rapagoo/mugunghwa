# 관절 움직임 시험 모드

## 실행과 시험

관절 엔진 실행 중인 Jetson 웹 `http://10.10.16.130:8080/`의 검증 영역에
관절 상태/점수/사용 관절 수/후보 이력을 추가했다. 기존 박스 중심 결과는 비교용으로 유지한다.
웹 버튼은 로컬 시험만 제어하며 음원·Pi C 클라이언트·STM·DB 판정과 아직 연결하지 않았다.

1. 구역을 설정하고 전신이 보이도록 선다. 웹에서 관절 표시를 확인한다.
2. 원하는 자세로 멈춘 다음 **정지 지시**를 누른다. 버튼을 누르러 움직이는 사람은
   다른 사람에게 조작을 맡기거나, 조작 후 제자리에서 다시 정지 지시를 받아야 한다.
3. 10초 정도 정지한다. 작은 흔들림으로 후보가 생기는지 확인한다.
4. **이동 허용**으로 후보를 지우고 자세를 준비한 뒤 다시 **정지 지시**한다.
   팔 들기, 느린 팔 이동, 몸 회전, 한 걸음 이동을 각각 시험한다.
5. 두 사람이 있으면 한 명만 움직여 다른 사람에게 후보가 붙지 않는지도 확인한다.

각 시험에서 기록 시작/중지를 사용하면 원본 JPEG와 `samples.jsonl`의 `pose_trial`에
점수·상태·후보·파라미터가 남는다. 시험마다 정지 지시를 새로 눌러 기준을 다시 잡는다.
`움직임 후보 기록됨`은 다음 지시까지 유지된다. 현재 상태가 정지로 돌아와도 후보는 유지된다.

## 점수와 보류 기준

- 정지 지시 이후 처음 처리하는 새 촬영 표본의 관절을 고정 기준으로 사용한다.
  명령 이전에 촬영된 표본은 기준으로 사용하지 않는다. 별도0.7초 유예는 없다.
  실제 STM 앞보기 완료 통지와 연결할 때의 의미를 로컬 정지 지시로 시험한다.
- 눈·귀·코는 제외하고 어깨/팔꿈치/손목/골반/무릎/발목을 사용한다.
  기준과 현재 모두 신뢰도≥0.5인 관절의 절대 위치 변화를 기준 박스 높이로 나눈다.
- 손목 하나의 변화가 몸 높이5%이거나, 손목 외 두 관절의 변화가 각각3%이면
  점수1에 해당한다. 점수는 두 조건 중 큰 값이며 확률/정확도/속도가 아니다.
- 점수≥1이0.2초 이상, 최소3개 연속 표본에 유지되면 시험 후보를 한 번 기록한다.
  시간 조건이 있어 좌표 한 번 튐과 순간 변화는 후보로 확정하지 않는다.
- 최소4개 관절과 어깨/골반 중2개가 공통 관측되어야 한다.
  움직임 근거가 없는데 팔 관절 일부가 보이지 않으면 정지라고 단정하지 않고 보류한다.
- 정지 시작 때 기준을 얻지 못한 ID, 새 ID, 추적 공백>0.5초 또는 구역 이탈 뒤에는 보류한다.
  같은 정지 구간에 새 자세를 기준으로 자동 재설정하지 않는다. 새 정지 지시가 필요하다.
- 구역 밖/통과 후보는 제외한다. 참가자 ID 연결·중복 박스 제거는 이번 변경에 포함하지 않았다.

신뢰도가 잠시 낮아지면 확인 시간을 끊고, 관측이 돌아오면 원래 기준과 비교한다.
관절0개/검출0명은 정지의 증거가 아니다. API `missing_ids`도 관찰해야 한다.
측면 회전·깊이 방향·아주 작은 동작·짧게 움직였다 돌아오는 동작은 여전히 놓칠 수 있다.
현재 임계값은 명확한 움직임부터 시험하기 위한 초기값이며 실제 오탐/누락률로 조정해야 한다.
