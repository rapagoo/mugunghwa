# 첫 촬영 영상 검출·설정 적용 결과

입력: `20261006_141148.mp4`와 사용자가 저장한 `calibration.json`.
1920×1080, 약 10.07초, 598프레임, 평균 약 59.43fps입니다.
영상·설정·분석 기록은 Jetson의 Git 제외 `data/video-tests/20261006-141148`와 `.runtime`에 보관했습니다.
Pi 게임·MCU에는 이 녹화 영상의 관측을 전송하지 않았습니다.

## 동일 YOLOv8n·ByteTrack 비교

| 항목 | 추론 입력 320 | 추론 입력 640 |
|---|---:|---:|
| 사람 검출 프레임 | 356 / 598 | 598 / 598 |
| 사람 미검출 프레임 | 242 | 0 |
| 영역 안 사람 검출 프레임 | 275 | 516 |
| ID 1이 부여된 프레임 | 319 | 585 |
| ID 1 최초 관측 | 약 4.69초 | 약 0.22초 |

640에서는 모든 프레임에 사람 박스 하나가 출력됐고, 초기 ID 미확정 13프레임 이후
ID 1이 끝까지 유지됐습니다. 수치는 이 영상의 관측 결과이며 일반적인 검출 정확도를 뜻하지 않습니다.
320에서는 초반 원거리 사람을 자주 놓칩니다. 이 영상 재생에는 `--imgsz 640`을 사용합니다.
기존 웹캠 기본값은 바꾸지 않았으며 실시간 속도와 카메라 구도는 별도 평가해야 합니다.

ROI는 복도 바닥, 결승선은 카메라 앞쪽, 통과 방향은 카메라 쪽으로 적용됐습니다.
추적된 박스 아래쪽 중앙이 지정 선분을 지정 방향으로 가로지르는 변화는
약 8.211~8.228초 사이에 1회 관측됐습니다. 이는 발 위치 기록을 이용한 사후 기하학 확인입니다.
참가자 등록·생존 상태·Pi 경기 단계를 검사한 게임 통과 판정은 아직 아닙니다.
영상 후반의 ROI 제외는 지정 구역에서 발 위치가 벗어난 것이며 탈락으로 처리하지 않습니다.
