# main 통합 검증 — 2026-10-12

## 범위

사용자 요청으로 개발 브랜치 pose-comparison의 코드를 main에 통합한다. 원격 fetch 후 origin/main 대비 개발 브랜치는53커밋 앞섰으며 main에만 있는 커밋은0이었다. 기능 기준은1a3581a(스피커 볼륨 롤백 검증)이며 이번 추가 변경은 문서와 로컬 발표 산출물 제외 규칙이다. 실행 중인 Pi·Jetson 배포나 펌웨어 업로드는 수행하지 않는다.

## 문서

README를 현재 기능·장치역할·실행·문서찾기·검증한계 중심으로 정리했다. Jetson/STM32 소개의 미구현 문구를 수정했고, 초기 설계/DB 문서는 당시 기록임을 명시해 현행 game-runtime 문서와 구분했다. 코드 해설의 삭제된 볼륨 API/파일 참조를 롤백 상태로 갱신했다.

11장 대본·발표자 배분·예상 질문30개·발표 검토 문서를 포함한다. 웹 발표 HTML과 생성 이미지는 별도 로컬 발표작업 폴더에서 관리하며 output은 Git 제외한다. 사용자 영상·음원·비밀값은 새로 추가하지 않는다.

## 남은 일

- OpenCV가 있는 영상 처리 환경에서 디코더 EOF/재시작 테스트 재실행.
- 서버의 남은 write 반환값/부분 송신 경로 보강. 강화 -Werror 빌드는 현재 실패하며 기본 빌드만 성공한다. 관련 TS-NET-001 기록 참고.
- 현장 전체 경기·장시간/단절 리허설,사진·시연 영상 추가,발표PC 확인.

기본 기능 통합과 검증 한계를 함께 공개한다. main 반영에는 force push를 사용하지 않는다.
