# 웹캠 1~3단계 검증

2026-10-07. 현재 웹: `http://10.10.16.130:8080/`.
메인 화면의 **웹캠 검증 · 1~3단계**에서 확인한다.
이 기능은 관측 검증용이며 Pi 게임 판정·MCU 명령·DB 결과를 만들지 않는다.

## 준비

- 두 사람의 전신과 발이 화면에 들어오도록 카메라를 고정한다. 발이 잘려 박스 아래쪽이
  화면 끝에 걸리면 구역/결승선 검증에 사용할 발 위치 추정이 부정확할 수 있다.
- 구역 설정에서 실제 바닥의 게임 영역·결승선·통과 방향을 지정한다.
- **시험 기록 초기화**를 누른 뒤 시험 번호가 증가하는지 확인한다.
  후보/관측 이력/통계를 초기화하며 구역 설정과 ByteTrack ID 자체는 유지한다.
  구역 변경·영상 반복·검출 재시작도 새 시험을 시작한다.

## 순서와 기대 결과

| 단계/장면 | 직접 확인할 것 | 기대 결과 |
|---|---|---|
| 1: 한 사람이 구역 진입/이탈 | 작은 발 점, IN/OUT, 구역 안/밖 인원 | 실제 위치와 일치. 진입/이탈 이력 기록 |
| 1: 가까운 곳/먼 곳, 두 사람 | 전체 인원, 신뢰도, ID 미지정 | 실제 사람 수와 비교. 신뢰도는 정확도 점수가 아님 |
| 2: 접근 쪽에서 지정 방향으로 넘기 | 접근 확인됨→선 넘음→통과 후보 | 같은 ID에 후보 1회 |
| 2: 반대로 넘기 | 선의 어느 쪽/후보 수 | 후보 0회 |
| 2: 선 끝 바깥으로 넘기 | 발 점이 유한 선분 끝 바깥을 지나는지 | 후보 0회 |
| 2: 선 가까이 정지/작게 흔들기 | 선 주변 표시/후보 수 | 여유 폭을 넘지 않으면 후보 0회 |
| 2: 도착 쪽에 처음 등장 | 접근 확인 대기 | 접근을 먼저 확인하지 않았으면 후보 0회 |
| 3: 두 사람이 서로 교차 | 교차 전후 각 사람 ID, 새 ID/미검출 이력 | 같은 사람 ID가 유지되는지 관찰 |
| 3: 한 사람이 다른 사람 뒤에 가림 | 미검출/재등장, 보이는 사람과 ID 연결 | 기존 ID 복구 또는 새 ID 여부를 기록 |

각 장면을 반복하려면 초기화한다. 같은 ID는 한 시험에서 한 번만 통과 후보가 된다.
결승선의 접근 쪽(-)에서 도착 쪽(+)으로 넘어야 하며, ROI/유한 선분/0.01 정규화 여유 폭/
최대 0.5초 관측 간격을 사용한다. 장시간 가림 후 위치가 뛰면 통과로 추정하지 않는다.
선과 방향은 사람의 박스 하단 중앙 기준이며 실제 발 위치/물리적 거리와 같다고 보장하지 않는다.

## 화면 읽기

- 박스: 초록=구역 안, 회색=구역 밖, 노랑=통과 후보. 작은 점=발 위치 추정.
- 사람별 표: 임시 ID, 검출 신뢰도, 구역, 정규화 좌표, 선의 어느 쪽, 통과 관측 상태.
- 관측 이력: 새 ID·구역 진입/이탈·0.5초 이상 미검출·같은 ID 재등장·통과 후보.
- 새 ID나 미검출은 실제 ID 교체를 확정하지 않는다. 사람이 화면 밖으로 나간 경우에도
  미검출로 표시된다. ID 교체·두 사람 ID 맞바뀜은 화면을 직접 비교해서 기록한다.
- 최근 이력은 서버에 60개, 화면에 30개. 최근 추적 정보는 최대 256개/30초 유지.
  '관측한 새 ID'는 신규 관측 이력 횟수이며 고유 참가자 수가 아니다.
- 영상 API는 약 1초 간격, DB API는 별도 약 2초 간격으로 조회한다.
  DB 조회 실패가 영상 관측 갱신을 지연시키지 않는다. 실제 추론/미리보기 FPS와는 별개다.

## 결과 기록

장면을 고른 뒤 예상 구역 인원·관찰 일치/문제 관찰/판단 전·메모를 입력하고
**현재 관측과 결과 기록**을 누른다. 그 시점의 서버 관측과 최근 이력을 함께 보관한다.
현재 검출 결과가 2초 이상 오래됐거나 입력이 준비/오류 상태라면 기록을 거부한다.
브라우저가 통신 실패했을 때도 마지막 값의 오래됨을 검사한다.
결과는 해당 페이지 메모리에 최대 30개 유지되므로 새로고침 전에 **검증 JSON 저장**을 누른다.
JSON에는 영상/사진이 없고 관측 ID·좌표·이력·메모가 포함된다. 파일은 Git에 추가하지 않는다.
이 결과는 사람이 관찰한 검증 의견이며 게임의 통과/탈락 결과와 분리된다.

## 검증 상태

- 자동 좌표 시험: 구역 진입/이탈, 정방향 후보 1회·반대 방향 0회,
  미검출/같은 ID 복귀, 새 시험 초기화, 이력/추적 정보 상한을 확인.
- 기존 유한 선분·흔들림·도착 쪽 최초 등장·가림 간격 배제 시험을 함께 실행.
- 실제 두 사람 이동/교차는 사용자와 함께 수행할 실장 시험이다.
  준비 도구와 합성 좌표 시험 통과를 실제 시연 정확도 검증 완료로 표현하지 않는다.
